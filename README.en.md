# IC35 Sync 3.4.0

Synchronize a Siemens IC35 with Thunderbird on Windows.

Download: https://github.com/ThunderSooS/ic35sync/releases/tag/v3.4.0

Close IC35 Sync, back up your data and run IC35-Sync-3.4.0-Setup.exe. Do not delete existing data folders or synchronization state.

Keep Thunderbird open, pair the bridge, select calendars and task lists, and start synchronization in the app. Press the dock button only when prompted. Select a text-file folder for notes.

Manual use requires the entire program folder including _internal. Do not copy only the EXE.

The bridge uses the independent version 3.4.0.13. Its manifest specifies Thunderbird compatibility. See RELEASE-NOTES.md for changes and remaining limitations, and CHANGELOG.md for historical entries.
